# Завдання 1

1. Виконати завдання щодо знаходження максимального призу мандрівником під час проходження ігрового середовища, репрезентованого завданням. Написати програму (функцію main), що містить опис середовища та функції щодо реалізації завдання.
2. Установити максимально можливий приз мандрівника та шлях проходження по шахівниці.
3. Вивести в консоль результати досліджень.
